# /git-push 명령어

로컬 Git 커밋 변경사항을 원격 저장소(`origin main`)로 푸시합니다.

## 절대 원칙
- 일반 작업 시에는 로컬 커밋(`git commit`)만 수행되며, 원격 푸시는 자동 실행되지 않습니다.
- 오직 사용자가 `/git-push`를 입력하거나 명시적으로 푸시를 요청할 때만 이 명령어를 통해 원격 푸시를 실행합니다.

## 실행 절차
1. `git status`로 로컬 변경사항 및 앞선 커밋 개수 확인
2. `git push origin main` 실행
3. 푸시 결과 및 커밋 로그를 사용자에게 보고
