# /gemini-ex 명령어

아래 엑셀 확인 및 미작업 항목 자동 작업 수행:
- **대상 스프레드시트**: https://docs.google.com/spreadsheets/d/1gk9U2sMDRvlOCsbquqSMqrnLrRJWpoijz6uGdKjxk-s/edit?gid=0#gid=0

## 실행 작업
1. 위 스프레드시트의 작업 목록을 확인하고 미작업(작업대기) 항목을 식별합니다.
2. 식별된 항목들의 기능, 버그 수정, UI 개선 및 번역 작업을 순차적으로 소스코드에 반영합니다.
3. `npm run lint`를 실행하여 에러가 없음을 검증합니다.
4. 작업 완료 후 커밋을 실행하고 `AGENTS.md` 진행 상태를 업데이트합니다.
