# /report-ex 명령어

아래 엑셀에서 작업완료되지 않은 작업대기 항목들을 작업하고 완료된 작업은 구글폼으로 작업완료 제출:
- **대상 스프레드시트**: https://docs.google.com/spreadsheets/d/1nX6BFBJR4fTrv3PMqG8UamwSbqY2tJt_VvJoGAPItu8/edit?usp=sharing

## 실행 작업
1. 위 스프레드시트에서 완료되지 않은 작업대기 항목을 식별합니다.
2. 각 요구사항에 따라 소스코드를 수정 및 구현합니다.
3. `npm run lint`로 타입을 검증합니다.
4. 작업 완료 후 안내받은 구글폼 제출 curl 명령어를 통해 작업완료 제출을 수행합니다.
5. `AGENTS.md` 진행 상태 목록에 결과를 업데이트하고 커밋합니다.
