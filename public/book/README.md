# 눈히어로 40부작

`sajo.txt`의 소설 본문 79개 장을 사건 순서대로 다시 나누어 각색한 판타지 웹소설입니다.

## 이름 기준

- 고유 이름을 가진 등장인물은 모두 SNSHero 110개 카드 중에서 골랐으며, 축약명이나 별칭 없이 공식 카드명을 사용했습니다.
- 주인공은 카드 41번 `카단`, 실리아는 카드 62번 `실리아`, 이그니스는 카드 11번 `이그니스`입니다.
- 카단의 아버지는 카드 50번 `알렉산다르`, 이름이 붙은 야생마는 카드 90번 `페가수스`, 고대 전략가는 카드 80번 `아이언포지`로 설정했습니다.
- `헤르쿨`은 카드 데이터베이스에 등록된 49번 공식 표기입니다.
- 110개 카드를 채우기 위해 배역을 억지로 추가하지 않고, 원작 사건에 필요한 인물만 사용했습니다.

## 각색 기준

- 무협 문파와 내공은 성소, 연맹, 마나 코어와 룬 전투술로 바꾸었습니다.
- 왕부, 비급, 죽장, 장풍 같은 소품과 표현은 판타지 궁정, 기억 장치, 녹옥 지팡이, 마나 충격으로 바꾸었습니다.
- 원문의 사건 순서와 인물 관계는 유지하되 문장은 모두 새로 집필했습니다.
- 카단의 정직함, 실리아의 지성과 주체성, 이그니스의 가족애와 권력욕이 서로의 선택에 영향을 주도록 서사를 연결했습니다.
