# /imp-mission 스킬 지침서

## 개요
SNSHero에 등록된 미션 게임들을 순차적으로 1개씩 선정하여 심층 코드 분석 및 4대 핵심 품질 평가를 수행합니다. 평가 결과에 따라 게임을 현대적 모바일 퓨어 제스처·1줄 슬림 HUD·확정 보상 체계로 전면 리팩토링 개선하거나, 완성도가 떨어질 경우 과감히 폐기하고 고품질 신규 3D 복셀 미션 게임으로 대체합니다. 작업 완료 후 `tsc --noEmit` 검증, Git 커밋/푸시, `WORK_LOGS.md` 기록 및 구글 폼 보고를 수행합니다.

---

## 4대 품질 평가 기준 (100점 만점)

1. **모바일 적합도 (25점)**:
   - `100dvh` 높이 및 뷰포트 오버플로우/스크롤 100% 방지
   - `DESIGN.md` 준수: 화면 상단 70% 시야 완전 개방, 최상단 5% 영역에 반투명 글래스모피즘 1줄 슬림 HUD(`MinimalistMissionHUD` / `ResponsiveCleanHUD` / `MobileSafeAreaHUD`) 배치
   - 모노스페이스 서체, 웜크림/잉크 팔레트, 1px 플랫 헤어라인 유지

2. **터치 플레이 편의성 (25점)**:
   - 화면을 가리는 가상 조이스틱/D-Pad/버튼 100% 철거
   - 순수 화면 제스처 기반 조작계(화면 드래그 조향/이동, 원터치 탭 액션, 더블탭 특수기, 롱프레스 차징, 스와이프 콤보/패링 등)
   - 터치 반응 영역 44px+ 및 하단 25% 썸존 제스처 격리

3. **게임 재미요소 및 몰입감 (25점)**:
   - Three.js 기반 직관적이고 반응성 높은 3D 복셀 물리 역학
   - 타격감, 속도감, 긴장감 및 콤보/피버/스턴트/부위파괴 등 시각/청각 피드백
   - 첫 진입 시 규칙/조작법/보상을 시연하는 3단계 인터랙티브 온보딩 모달(`UniversalTutorialModal` / `SportsMissionTutorial`) 및 로컬스토리지 영구 보존 연동

4. **보상 난이도 및 형평성 (25점)**:
   - "보상 없는 게임 0건" 정책 준수
   - 분당 50P 표준 및 난이도/스킬 승수 계산 기반 `calculateAndDepositMissionReward` 게이트웨이 연동
   - 클리어 즉시 유저 로컬스토리지 지갑 원자적 즉시 입금
   - 승리 화면 2초 황금 코인 팡파레 및 투명 보너스 내역 인포그래픽 팝업(`VictoryRewardModal`)

## 수행 절차

### 1단계: 순차적 대상 게임 선정
- `AGENTS.md`의 `imp-mission 마지막 점검 게임`을 확인합니다.
- `src/components/Voxel*Game.tsx` 및 미션 게임 목록 중 다음 순번의 게임 컴포넌트 1개를 추출합니다.
- (예: `VoxelArcherHeroGame` ➔ `VoxelDragonSlayerGame` ➔ `VoxelTankBounceGame` ➔ `VoxelNinjaSlashGame` ➔ ...)

### 2단계: 코드 심층 분석 및 4대 평가 점수 산출
- 대상 파일의 Three.js 씬 구성, 이벤트 리스너, 제스처 핸들러, HUD 레이아웃, 보상 입금 로직을 정밀 분석합니다.
- 4대 평가 기준에 따른 점수(총 100점 만점)와 구체적 분석 의견을 도출합니다.

### 3단계: 개선 또는 폐기/신규 대체 결정 및 구현
- **점수 80점 이상 (개선 가능)**:
  - 퓨어 제스처 컨트롤러 연동
  - 상단 1줄 슬림 글래스 HUD 적용
  - 3단계 온보딩 튜토리얼 모달 연동
  - `VictoryRewardModal`을 통한 100% 확정 SNS 보상 정산 연동
- **점수 80점 미만 (완성도 미달 / 물리 버그 / 구조적 결함)**:
  - 기존 컴포넌트를 과감히 폐기하고, 고품질 신규 3D 복셀 미션 게임으로 전면 재작성하여 대체
  - 최신 퓨어 제스처, 1줄 HUD, 3단계 튜토리얼, 표준 보상 팝업을 기본 내장하여 구현

### 4단계: TypeScript 무결성 검증
- `./node_modules/.bin/tsc --noEmit` 명령어를 실행하여 0 오류 통과를 확인합니다.

### 5단계: Git 커밋 & 푸시
- 변경 사항을 명확한 커밋 메시지로 즉시 커밋하고 `origin/main`으로 푸시합니다.
  ```bash
  git add [수정/생성 파일들] AGENTS.md WORK_LOGS.md
  git commit -m "feat(mission): [imp-mission] [개선/대체] [게임명] 퓨어 제스처 및 확정보상 고도화"
  git push origin main
  ```

### 6단계: 영구 로그 기록 및 구글 폼 제출
- `WORK_LOGS.md`에 평가 점수표, 주요 수정 내역, 검증 결과를 누적 기록합니다.
- `AGENTS.md`의 `imp-mission 마지막 점검 게임` 상태를 최신화합니다.
- 검증 완료된 구글 폼 제출 스크립트로 즉시 보고서를 전송합니다:
  ```bash
  python3 skills/report-ex/scripts/submit_report.py --dept "개발" --task "[imp-mission] [게임명] 평가 및 개선/대체 완료" --status "작업완료" --details "[4대 평가 점수 및 작업 상세 내용]"
  ```

### 7단계: 사용자 상세 보고
- 4대 기준 평가 점수, 개선/대체 전후 비교, 빌드 검증 결과, 커밋 및 구글 폼 제출 완료 내역을 한국어로 명확히 보고합니다.
