# /git-push 스킬 지침서

## 개요
이 스킬은 사용자가 `/git-push` 명령어를 입력하거나 명시적으로 원격 저장을 요청할 때만 로컬 Git 커밋들을 `git push origin main`으로 원격 저장소에 반영합니다.

## 절대 원칙
- 일반적인 코드 수정 및 작업 완료 시에는 **로컬 커밋(`git commit`)만 수행**하고 **원격 푸시는 절대 자동으로 실행하지 않습니다.**
- 오직 사용자가 `/git-push`를 직접 호출하거나 명시적으로 "푸시해줘"라고 요청할 때만 이 스킬의 푸시 명령을 실행합니다.

## 수행 절차
1. **로컬 Git 상태 확인**:
   ```bash
   git status
   ```
2. **원격 푸시 실행**:
   ```bash
   git push origin main
   ```
3. **결과 보고**:
   푸시 성공 여부 및 최신 커밋 해시/내역을 사용자에게 한국어로 안내합니다.
