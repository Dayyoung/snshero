## 3. 타이포그래피 & 상용 조형 카드 프레임
- **전면 나눔고딕 통일**: `--hs-font-sans: 'Nanum Gothic', '나눔고딕', sans-serif`를 모든 타이틀, 카드명, 능력 설명문, 스탯 숫자, Canvas 전투 플로팅 텍스트에 일괄 적용합니다.
- **입체 종족 프레임 (`CardVisual.tsx`)**:
  - 종족별 고유 금속 베젤 컬러, 타원형 영웅 초상화 포트, 아치형 양피지 리본 타이틀, 하단 양피지 텍스트 스크롤 박스
  - 보석 스탯 오브: 사파이어 마나 결정(좌상단), 황금 검 공격력 오브(좌하단), 루비 생명력 물방울(우하단)
  - 전설 등급 쌍익 크레스트(`SnsLegendaryCrestSvg`), 도발 철갑 방패(`SnsTauntShieldSvg`), 성흔 보호막 돔(`SnsDivineBarrierSvg`)

## 4. 모바일 포트레이트 반응형 & 카드 확대 인터랙션 (`CardZoomModal`)
- 모바일 세로 화면(`360px~430px`)에서 모든 상단 메뉴, 대전 시작 버튼, 상대 손패, 턴 종료 레버, 감정표현, 손패 팬이 잘림 없이 노출됩니다.
- **원터치 확대 → 하단 실행 / 외곽 취소**:
  - 작은 카드를 클릭/터치하면 즉시 내거나 교체하지 않고 `CardZoomModal`로 크게 확대하여 텍스트와 종족/영웅 정보를 선명하게 표시합니다.
  - 모달 하단 실행 버튼(`카드 사용`, `덱에 카드 넣기`, `교체 표시하기` 등)으로 동작을 확정하며, 외곽 배경을 터치하면 즉시 선택이 취소됩니다.
- **성흔 팩 개봉 연출 (`PackOpeningScreen`)**:
  - 5장의 카드가 공중에 둥둥 떠다니며(`hsPackCardFloat`), 개별 터치 또는 `5장 한 번에 뒤집기` 클릭 시 순차적 3D Y축 회전(`preserve-3d`)과 등급별 광휘 파동이 발동합니다.

## 5. 프로덕션 클린 UI & 개발자 콘솔 테스트 API
- 상용 화면에서 `REA 검증` 및 `전체해금` 등 테스트용 UI 버튼을 모두 제거했습니다.
- 브라우저 개발자 도구(F12 Console)에서 `window.snshero` (별칭 `window.noonhero`) 객체로 모든 검증 및 치트 명령을 실행할 수 있습니다:
  - `snshero.help()`: 콘솔 명령어 도움말 출력
  - `snshero.unlockAll()`: 382종 전체 카드 해금 (일반 2장 / 전설 1장)
  - `snshero.addGold(1000)` / `snshero.addDust(1600)` / `snshero.addPacks(10)`
  - `snshero.setRank(0)` / `snshero.completeQuests()`
  - `snshero.verifyRoster()`: 382종 종족 배분(`9×25 + 110 + 47`) 실시간 무결성 검증
  - `snshero.reset()`: 저장 데이터 초기화
