# Poki No.001 - Slime Keyboard Escape 구현 프롬프트

## 1. 원본 게임 분석 요약 (Poki Official)
- **게임명**: Slime Keyboard Escape (제작사: Blasters)
- **장르**: 3D 액션 플랫폼 / 키보드 오비(Obby) 탈출 러너
- **그래픽 엔진**: 3D WebGL / Three.js 기반
- **배경 컨셉**: 
  - 거대한 컴퓨터 기계식 키보드 자판(Keycaps)으로 이루어진 초현실적 3D 플랫폼 월드.
  - 키캡들 사이에 낭떠러지(낙사 존), 끈적거리는 초록 슬라임 웅덩이 트랩, 강력한 가속 부스터 발판이 배치됨.
- **핵심 메커니즘**:
  1. **스피드 누적 (Speed Scaling)**: 키보드 위를 멈추지 않고 점프하며 달릴수록 슬라임의 질주 속도가 점진적으로 상승 (+Speed 축적).
  2. **3D 점프 및 낙사 회피**: 3D 공간 상에서 각기 다른 높이와 간격으로 배열된 키캡 사이를 점프하여 결승 [ESC] 키 포털까지 도달.
  3. **3인칭 추적 카메라**: 슬라임의 이동 방향을 부드럽게 추적하는 3D 시점.
  4. **모바일 퓨어 제스처**: 화면 좌우 스와이프 조향, 탭 점프, 롱탭 가속 부스트.
