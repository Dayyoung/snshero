# No.062 Blast Buddies 3D 리마스터 기획 및 설계 프롬프트

## 1. 게임 개요
- **게임명**: Blast Buddies 3D (블래스트 버디즈 3D)
- **원작 식별**: Poki 인기 순위 62위 (`https://poki.com/kr/g/blast-buddies`)
- **장르**: 3D 봄버 아레나 배틀 / 실시간 폭탄 설치 서바이벌
- **기술 스택**: React 19 + Three.js + TypeScript + Tailwind CSS
- **연동 카드**: No.062 공식 영웅 배지 (`drawCardSprite(ctx, 62, ...)`)

## 2. 3D 그래픽 및 블록 아레나 연출
1. **3D 11x11 블록 아레나 (Block Arena)**:
   - 11x11 그리드 타일 (가로 22m x 세로 22m), 견고한 외벽과 규칙적으로 배치된 16개의 불괴(Indestructible) 석재 기둥.
   - 맵 전체에 무작위 배치된 25개의 파괴 가능(Destructible) 우드 크레이트 상자.
   - 플레이어는 남서쪽 안전 시작 지점(코너 3칸 안전 확보, 스폰 즉시 급사 원천 차단).

2. **3D 캐릭터 & 폭탄 모델링**:
   - **플레이어 (블루 버디)**:
     - 블루 바이저 헬멧, 앙증맞은 3D 바디, No.062 공식 카드 영웅 배지 부착.
     - 부드러운 아날로그 롤링 보행 모션.
   - **라이벌 버디 (AI 3인)**:
     - 레드, 옐로우, 퍼플 버디. 장애물 우회 및 폭탄 회피 AI, 아이템 파밍 알고리즘 탑재.
   - **3D 시한폭탄 (Bomb)**:
     - 검은 유광 구체, 타오르는 심지 스파클 파티클, 폭발 직전 팽창 바운스 애니메이션 (2.5초 카운트다운).
   - **3D 십자형 폭발 화염 (Crossfire Blast)**:
     - 상하좌우로 뿜어져 나오는 3D 불꽃 큐브/실린더 기둥, 크레이트 파괴 및 적 버디 즉사 판정.

3. **파워업 아이템 (Power-Up Pickups)**:
   - 크레이트 파괴 시 확률적 드롭:
     - 1) 화력 증가 (Fire Range +1): 화염 반경 1칸 확장
     - 2) 폭탄 개수 (Extra Bomb +1): 동시 설치 폭탄 +1
     - 3) 속도 부스트 (Speed Up +1): 이동 속도 +20%

4. **카메라 워크**:
   - 탑다운 쿼터뷰 아레나 시점: 11x11 전장이 한눈에 들어와 폭탄의 화염 경로와 적의 위치를 즉시 파악할 수 있는 시원한 뷰.

## 3. 핵심 게임플레이 및 모바일 인터랙션
1. **봄버 서바이벌 규칙**:
   - 폭탄을 설치하여 장애물 상자를 부수고 아이템을 획득.
   - 십자 화염에 닿으면 즉시 탈락!
   - 3명의 라이벌 버디를 모두 폭파시키고 최후의 1인으로 살아남으면 승리!

2. **모바일 퓨어 터치 인터랙션 (Pure Touch Control)**:
   - **좌측 영역**: 360도 다이나믹 플로팅 조이스틱 (Screen-relative 완벽 일치, 부드러운 아날로그 그리드 이동).
   - **우측 액션 버튼**: 대형 76px [BOMB 폭탄 설치] 버튼 (터치 시 발 밑 타일에 폭탄 드롭 + 햅틱 피드백).
   - 폭탄 설치, 파워업 획득, 폭발 시 즉각적인 햅틱(`navigator.vibrate`) 연동.

3. **UI 및 표준 보상 정산**:
   - 상단 MinimalistMissionHUD: 생존 버디(4 ➔ 1), 현재 화력, 보유 폭탄 수, 점수, 중도 포기 확인 및 실적 비례 SNS 안전 정산.
   - VictoryRewardModal: 최후의 생존자 승리 시 35~50 SNS 포인트 및 영웅 카드 No.062 정산.
