# Poki No.093: Car Circle (Three.js 3D 리마스터 기획 프롬프트)

## 1. 게임 개요
- **게임명**: Car Circle 3D
- **장르**: 3D 원형 로터리 차량 합류 & 타이밍 트래픽 컨트롤 퍼즐
- **카테고리**: 두뇌 게임, 스킬 게임, 아케이드 게임
- **원작 URL**: https://poki.com/kr/g/car-circle
- **연동 카드**: No.093 영웅 카드 (`drawCardSprite` 로터리 중앙 기념탑 및 진입 차량 보닛 데칼)

## 2. 핵심 게임 메커니즘
1. **3D 메가 로터리 시티 교차로**:
   - 반경 6.2m 아스팔트 원형 트래픽 루프 및 4방향 접속 도로.
   - 로터리 중앙 원형 잔디 아일랜드에 No.093 공식 카드 영웅 배지 기념탑 각인.
2. **다이나믹 트래픽 회전 차량군**:
   - 3~4대의 다양한 색상(블루 세단, 에메랄드 택시, 앰버 SUV) 3D 차량들이 일정한 속도로 루프를 순환 주행.
   - 타이어 회전, 헤드라이트 빔 조명.
3. **타이밍 발차 & 합류(Merge) 시스템**:
   - 남쪽 진입로에서 대기 중인 레드 스포츠카(보닛 No.093 영웅 배지 부착).
   - 화면 탭 또는 76px [🚗 MERGE NOW!] 버튼 터치 시 진입로를 따라 출발하여 로터리에 합류.
   - 로터리 주행 중인 차량과 0.8m 이내 충돌 시 폭발 스파크 및 하트 1개 감소.
   - 완벽한 타이밍에 빈틈을 파고들면 "PERFECT MERGE! +100" 세레모니 및 합류 차량이 로터리 트래픽에 동기화.
   - 총 12대 무사 합류 성공 시 승리 세레모니 및 콘페티 폭발.
4. **모바일 퓨어 터치 조작계 (100% 모바일 제스처)**:
   - 가상 D-패드 배제.
   - 화면 어디든 원터치 탭 또는 76px [🚗 MERGE NOW!] 대형 타이밍 버튼.
   - 우측 64px [⏱️ SLOW-MO] 슬로우모션 3초 힌트 버튼 + 햅틱 연동.
   - `MinimalistMissionHUD` (합류 성공 12대 진행도, 하트 3개, 포기 확인 모달, 실적 비례 20~50 SNS 안전 정산).

## 3. 기술 스택
- React 19 + TypeScript + Three.js + Tailwind CSS 4
- `drawCardSprite(heroCtx, 93, 18, 18, 220, 220, { circleClip: true })`
- `calculateAndDepositMissionReward` 표준 리워드 게이트웨이
