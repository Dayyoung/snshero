# No.059 Red Ball 4 3D 리마스터 기획 및 설계 프롬프트

## 1. 게임 개요
- **게임명**: Red Ball 4 3D (레드 볼 4 3D)
- **원작 식별**: Poki 인기 순위 59위 (`https://poki.com/kr/g/red-ball-4`)
- **장르**: 3D 물리 기반 볼 롤링 플랫포머 어드벤처
- **기술 스택**: React 19 + Three.js + TypeScript + Tailwind CSS
- **연동 카드**: No.059 공식 영웅 배지 (`drawCardSprite(ctx, 59, ...)`)

## 2. 3D 그래픽 및 환경 연출
1. **3D 플랫포머 롤링 트랙 환경**:
   - 100m 길이의 3D 초록 언덕 플랫포머 트랙 (스타트 광폭 15m 안전 발판, 오르막 언덕, 점프대 램프, 움직이는 부유 섬 발판, 피니시 깃발 광장).
   - 파란 하늘과 뭉게구름, 따스한 선샤인 엠비언트 조명 연출.
   - 추락 시 안전 리스폰(Checkpoint) 시스템.

2. **3D 캐릭터 & 오브젝트 모델링**:
   - **플레이어 (Red Ball)**:
     - 새빨간 고광택 구체, 깜찍한 만화풍 눈과 미소 텍스처 매핑.
     - No.059 공식 카드 영웅 배지 부착.
     - 구를 때 전방 회전 물리 및 지면 착지 시 바운스 스쿼시 연출.
   - **사악한 블랙 스퀘어 미니언 (Black Square Minions)**:
     - 뿔테 안경과 찡그린 눈을 가진 3D 정육면체 큐브 몬스터 3마리.
     - 좌우 순찰 이동. 위에서 점프로 밟으면(Stomp) 납작하게 찌그러지며 처치.
   - **3D 황금 별 (Golden Stars)**:
     - 공중에 떠서 360도 자전하는 5개의 입체 황금 별 (획득 시 영롱한 챠임 사운드 & 골든 스파클).
   - **골인 깃발 (Finish Flag)**:
     - 깃대와 펄럭이는 붉은 체크 깃발, 도달 시 축포 팡파르 발동.

3. **카메라 워크**:
   - 횡스크롤 3D 시점 (Side-scrolling 3.5D): Red Ball의 이동과 점프 높이를 부드럽게 추적하며 전방 시야를 시원하게 확보.

## 3. 핵심 게임플레이 및 모바일 인터랙션
1. **플랫포머 롤링 메커니즘**:
   - 관성과 마찰력이 적용된 3D 롤링 물리.
   - 언덕 경사면 가속도 및 램프 도약 물리.
   - 하트 3개 생명력 시스템: 몬스터 정면 충돌 시 하트 1개 차감 및 무적 깜빡임.
   - 몬스터 스톰프 처치: 공중 낙하 중 미니언 머리를 밟으면 높이 반동 도약(Super Bounce) + 몬스터 격파 점수.

2. **모바일 퓨어 터치 인터랙션 (Pure Touch Control)**:
   - **좌측 영역**: 좌우 롤링 터치 슬라이더 (Screen-relative 완벽 일치, 좌측 터치 시 좌회전, 우측 터치 시 우회전 롤링).
   - **우측 액션 버튼**: 대형 76px [JUMP 점프] 버튼 (터치 시 힘차게 도약 + 햅틱 피드백).
   - 모든 타격, 별 수집, 피니시 도달 시 햅틱(`navigator.vibrate`) 연동.

3. **UI 및 표준 보상 정산**:
   - 상단 MinimalistMissionHUD: 수집한 별(0/5), 남은 생명 하트(❤️❤️❤️), 스코어, 중도 포기 확인 및 실적 비례 SNS 안전 정산.
   - VictoryRewardModal: 피니시 깃발 도달 시 35~50 SNS 포인트 및 영웅 카드 No.059 정산.
