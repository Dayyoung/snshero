# No.021 Steal a Brainrot 3D (브레인롯 탈취 3D) 리마스터 프롬프트

## 1. 개요 및 원작 분석
- **원작 게임**: [Poki - Steal a Brainrot](https://poki.com/kr/g/steal-a-brainrot)
- **장르**: 3D 잠입 액션, 기지 침투 탈취(Heist), 고속 탈출 어드벤처
- **특징**: 적의 첨단 보안 기지에 은밀히 잠입하여 감시 드론의 시야를 피하고, 볼트 중앙의 황금 'Brainrot Core'를 탈취한 뒤, 기지 전체에 사이렌이 울리는 비상 록다운 상황 속에서 추격을 따돌리고 안전 탈출구로 탈출하는 스릴 넘치는 잠입 탈취 게임.

## 2. 3D 그래픽 및 월드 구성 (Three.js)
1. **32m x 28m 보안 기지 볼트 (Security Vault Arena)**:
   - 바닥(메탈릭 하이테크 그리드 타일), 벽면(네온 사이안/다크 그레이 보안 벽), 기둥 및 엄폐 오브젝트.
   - **시작 지점 안전 안착 원칙**: 서쪽 헬리패드(X: -12m, Z: 0)는 감시가 닿지 않는 안전 탈출 구역으로 시작 급사 원천 차단.
   - 중앙 볼트 챔버(X: 10m, Z: 0): 공중에 떠서 빛을 뿜는 황금 브레인롯 코어(Golden Brainrot Core).
2. **보안 가드 드론 & 시야각(Vision Cone)**:
   - 3대의 정찰 가드 드론이 기지 내부를 패트롤 순찰.
   - 전방으로 비추는 45도 반투명 시야 원뿔(평상시 노란색, 플레이어 발견 시 붉은색 전환).
   - 플레이어가 시야 콘에 닿거나 브레인롯을 탈취하면 즉시 [비상 경보 ALARM] 발령!
3. **비상 경보 & 탈출 추격 시스템**:
   - 브레인롯 탈취 시 전체 조명이 붉은색으로 점멸하며 긴박한 사이렌 가동.
   - 모든 가드 드론이 붉은 안광과 함께 플레이어를 향해 가속 추격.
   - 플레이어는 스프린트 대시를 활용하여 서쪽 안전 헬리패드로 복귀해야 함.
4. **플레이어 요원 메쉬**:
   - 3D 잠입 요원 아바타 (스텔스 슈트, 네온 바이저, No.021 공식 영웅 카드 스프라이트 HUD 배지).

## 3. 모바일 편의성 및 100% 퓨어 터치 절대 원칙
1. **화면 왜곡 원천 차단**:
   - `fixed inset-0 w-full h-[100dvh] overflow-hidden select-none touch-none`
   - `ResizeObserver` 및 `orientationchange` 대응으로 100% 모바일 전체화면 유지.
2. **카메라 시점 일치 조작**:
   - 3인칭 쿼터뷰 탑다운 시점 (화면 오른쪽 = `+X`, 화면 왼쪽 = `-X`, 전방 = `-Z`).
   - 사용자 화면 기준 360° 이동 방향 100% 일치.
3. **직관적인 모바일 퓨어 터치 UI**:
   - 좌측 화면 터치 드래그로 360° 부드러운 이동 (다이나믹 조이스틱).
   - 우측 80px 대형 [⚡ 스프린트/대시] 버튼 (스태미나 가속으로 시야 통과 및 알람 탈출).
   - 피격/수집/스프린트 시 햅틱 진동(`navigator.vibrate`) 피드백.

## 4. 보상 및 데이터 영구 보존

- `localStorage` 기반 무결점 영구 보존.
