# No.075 Color Artist Three.js 3D 리마스터 기획 프롬프트

## 1. 게임 개요
- **게임명**: Color Artist (컬러 아티스트 3D)
- **원작 출처**: Poki 인기 게임 110선 No.075 (라인 76)
- **장르**: Three.js 기반 3D 입체 복셀 컬러링 & 아트 갤러리 시뮬레이션
- **타겟 플랫폼**: 모바일 퓨어 터치 (100dvh 무결점 뷰포트, Screen-relative 완벽 일치, 가상 D-패드 배제)

## 2. 3D 전장 및 그래픽 사양
- **3D 아틀리에 갤러리 룸**:
  - 부드러운 앰비언트 스튜디오 조명, 회전식 갤러리 페데스탈(Pedestal) 받침대.
  - 받침대 전면 No.075 공식 카드 영웅 배지 엠블럼 부착 (`drawCardSprite(ctx, 75, ...)`).
  - 360도 궤도 회전(Orbit Rotation): 손가락 스와이프로 3D 조각상을 상하좌우 부드럽게 회전.
- **3D 입체 복셀 조각상 (Voxel Masterpiece)**:
  - 64개(4x4x4)의 정육면체 복셀 블록으로 구성된 입체 마스코트 조각상.
  - 각 복셀 블록은 1~6번까지의 지정 번호를 가지며, 초기 미도색(그레이스케일) 상태.
  - 번호별 컬러 매핑:
    - 1번: 썬 옐로우 (`#fde047`, `0xfde047`)
    - 2번: 네온 오렌지 (`#f97316`, `0xf97316`)
    - 3번: 스카이 블루 (`#38bdf8`, `0x38bdf8`)
    - 4번: 로열 바이올렛 (`#a855f7`, `0xa855f7`)
    - 5번: 에메랄드 그린 (`#10b981`, `0x10b981`)
    - 6번: 펄 화이트 (`#ffffff`, `0xffffff`)
- **인터랙션 및 시각 효과**:
  - 선택한 번호와 일치하는 복셀 블록은 반짝이는 펄스 하이라이트.
  - 채색 시 팝업 바운스 스케일 애니메이션 및 컬러 스파클 파티클 방출.
  - 100% 완성 시 황금 축포 컨페티 & 360도 공중 부유 쇼케이스.

## 3. 플레이어 조작계 (모바일 퓨어 터치)
- **화면 드래그 3D 궤도 회전**:
  - 화면을 드래그하여 조각상을 상하좌우 자유롭게 회전 관찰.
- **하단 모바일 컨트롤 바**:
  - 1~6번 컬러 팔레트 선택 바 (해당 번호의 남은 블록 수 표시).
  - **76px PAINT (연속 채색)**: 누르고 있으면 현재 시야 내 일치하는 번호의 블록들을 연속 자동 채색.
  - **64px SPRAY (광역 스프레이)**: 현재 선택한 번호의 인접 블록들을 한 번에 광역 채색.
- **햅틱 피드백**: 블록 채색 톡, 스프레이 럼블, 100% 완성 팡파레 진동.

## 4. 카메라 및 승리 조건
- **3.5D 갤러리 포커스 카메라**:
  - 조각상의 중심을 바라보며 모든 각도에서 최적의 원근감을 제공하는 궤도 카메라.
- **승리 조건**:
  - 전체 복셀 블록을 100% 채색 완료 시 승리 & VictoryRewardModal 연동.
- `MinimalistMissionHUD` 연동 및 20~50 SNS 안전 정산.
