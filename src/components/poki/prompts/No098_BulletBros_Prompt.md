# No.098 Bullet Bros (Three.js 3D 도탄 물리 불릿타임 슈팅 액션)

## 1. 게임 개요
- **원작 타이틀**: Bullet Bros (`https://poki.com/kr/g/bullet-bros`)
- **장르**: 3D 탄도 슈팅 / 도탄 물리 퍼즐 / 불릿타임 액션 플랫폼
- **플랫폼**: 모바일 웹 (Three.js + React 19 + TypeScript + Tailwind CSS)
- **공식 연동 영웅**: No.098 공식 카드 영웅 배지 (`cards1.png` / `cards2.png` 스프라이트 연동)

---

## 2. 게임 메커니즘 및 3D 구현 사양

### (1) 3D 사이버 옥상 전장 스테이지
- **18m x 12m x 8m 네온 루프탑 아레나**:
  - 네온 블루/마젠타 조명, 야간 도시 스카이라인 배경.
  - 강철 벽면 및 반사 기둥 (총알이 부딪히면 황금 스파크를 튀기며 도탄).
  - 스테이지 중앙 상단 No.098 공식 카드 영웅 배지 홀로그램 네온 전광판.

### (2) 3D 브로 히어로 & 적 요원 모델링
- **플레이어 (블랙 트렌치코트 브로 요원)**:
  - 스타일리시한 선글라스, 듀얼 매그넘 권총, 가슴/등 No.098 공식 영웅 배지 엠블럼.
  - 조준 시 레이저 사이트 궤적 방출.
- **적 요원 피규어**:
  - 레드 타이/선글라스의 AI 적 요원들.
  - 피격 시 3D 래그돌 텀블링 및 사방으로 튕겨 날아가는 피격 세레모니.

### (3) 도탄(Ricochet) & 불릿타임 메커니즘
- 탄환 발사 시 실시간 3D 궤적 및 벽면 반사(최대 3회 도탄).
- 총알이 적과 충돌 시 화려한 슬로우모션 킬캠 및 스파크 폭발.
- 3개 웨이브 스테이지 클리어 시 챔피언 세레모니 및 승리 트로피 연동!

### (4) 모바일 퓨어 터치 조작계
- **화면 드래그 조준**: 터치 지점에서 반대 방향으로 드래그하여 레이저 탄도선 실시간 프리뷰 (Screen-relative 완벽 일치).
- **76px [💥 SHOOT / TRIGGER] 대형 격발 버튼**: 원터치 즉시 발사.
- **64px [⏱️ BULLET TIME] 슬로우모션 토글 버튼**: 시간 0.25배속 감속 정밀 조준.
- 햅틱 진동 피드백 (`navigator.vibrate`) 연동.

---

## 3. 보상 및 UI 규격
- **MinimalistMissionHUD**: 적 소탕 수, 남은 탄환 수, 스테이지 진행도(1~3), 중도 포기 확인 모달, 실적 비례 20~50 SNS 포인트 안전 정산.
- **VictoryRewardModal**: 전 스테이지 소탕 시 360도 매트릭스 불릿타임 쇼케이스 세레모니 및 보상 지급.
- **LocalStorage 100% 영구 보존**: `calculateAndDepositMissionReward` 표준 게이트웨이 연동.
