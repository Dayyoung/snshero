# No.013 Talking Tom Gold Run (Three.js 3D 3레인 골드 러너) 구현 프롬프트

## 1. 게임 개요
- **게임명**: Talking Tom Gold Run (Poki No.013)
- **원본 링크**: https://poki.com/kr/g/talking-tom-gold-run
- **장르**: 어드벤쳐 게임, 스킬 게임, 3D 3레인 엔드리스 러너
- **엔진**: Three.js (WebGL 3D)
- **목표**: 도둑 라쿤을 추격하며 3차선 고속도로 도시 트랙을 질주하여, 버스·트럭·바리케이드·도로 표지판을 점프와 슬라이딩으로 회피하고 반짝이는 황금 금괴와 자석 파워업을 수거하여 최고 거리 및 골드 점수를 달성하기.

## 2. 3D 시각적 요소 및 씬 구성
1. **카메라 및 환경**:
   - `PerspectiveCamera` 3인칭 백뷰 러너 시점: `fov: 60`, `position: (0, 4.5, 8)`, `lookAt: (0, 1.5, -12)`.
   - 3차선 도로 아스팔트 트랙 (좌: -3.2, 중: 0, 우: +3.2), 차선 점선 표시, 양옆 가로수 및 도시 빌딩 실루엣.
   - 전방 안개 효과 `THREE.FogExp2(0x1e293b, 0.012)`로 무한히 펼쳐지는 3D 도시 고속도로 연출.
2. **장애물 및 아이템 (Dynamic Spawners)**:
   - **안전 스타트 존**: 시작 지점 `Z: 10 ~ -25` 구간은 장애물이 없는 35m 광폭 안전 구간 (시작 낙하/충돌 방지).
   - **버스 / 택배 트럭 (Bus Obstacles)**: 차선 1개를 막고 서 있는 대형 차량 (좌/우 회피 필요).
   - **낮은 바리케이드 (Low Barriers)**: 점프로 뛰어넘어야 하는 도로 공사 바리케이드.
   - **높은 오버헤드 사인 (High Overhead Signs)**: 웅크리기 슬라이드로 통과해야 하는 상단 차단봉.
   - **황금 금괴 (Gold Bars)**: 레인마다 줄지어 늘어선 반짝이는 3D 금괴 (수집 시 +20점).
   - **골드 자석 (Magnet Powerup)**: 획득 시 6초간 3차선 전체의 금괴를 플레이어에게 자석처럼 끌어당김!
3. **3D 토킹톰 스타일 아바타**:
   - 귀여운 고양이 귀 머리(카툰 눈 & 코), No.13 카드 영웅 배지가 새겨진 가슴팍, 전력 질주 보행 및 회전 점프 애니메이션.

## 3. 조작 및 모바일 퓨어 터치 (100% 모바일 편의성)
1. **화면 스와이프 제스처**:
   - 좌/우 스와이프: 즉각 3차선 변경 (부드러운 레인 Lerp 전환).
   - 상단 스와이프: 3D 높이 점프 (`vy = 16`).
   - 하단 스와이프: 몸을 둥글게 굴리며 1.0초간 슬라이딩.
2. **엄지 최적화 하단 터치 버튼**:
   - 좌측: `[◀]` / `[▶]` 차선 이동 버튼.
   - 우측: `[▲ JUMP]` 점프 버튼, `[▼ ROLL]` 슬라이드 버튼.
3. **햅틱 피드백**:
   - 금괴 수집 시 미세 진동, 점프/착지 및 충돌 시 역동적 진동 반응.

## 4. HUD 및 보상 시스템
- 실시간 달린 거리(Meters), 수집한 금괴(Gold), 자석 파워업 타이머, 콤보 배율.
- `MinimalistMissionHUD` 연동:
  - 뒤로가기 클릭 시 즉시 종료되지 않고 보상 보존 팝업 표시.
  - 중도 포기 시에도 지금까지 질주한 거리와 금괴 수집량에 비례하여 공정 보상(20~50 SNS) 영구 지급.
