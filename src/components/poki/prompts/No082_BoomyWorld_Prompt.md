# No.082 Boomy World - Three.js 3D 봄버 아레나 & 십자 화염 연쇄 폭발

## 1. 개요
- **게임명**: Boomy World (부미 월드 3D)
- **장르**: 액션 아케이드, 봄버 배틀, 3D 연쇄 폭발 퍼즐
- **플랫폼**: Poki 웹게임 Top 110선 No.082
- **원작 URL**: `https://poki.com/kr/g/boomy-world`
- **엔진**: Three.js (WebGL 3D) + React 19 + TypeScript + Tailwind CSS

---

## 2. 핵심 게임 메커니즘 & 3D 연출
1. **3D 봄버 미로 아레나 (3D Block Maze Arena)**:
   - 11 x 11 타일 격자형 3D 배틀 필드 (견고한 외벽, 파괴 불가능 석조 기둥, 파괴 가능한 나무 보물 상자, 중앙 No.082 공식 카드 영웅 배지 엠블럼).
   - 3.5D 스무스 톱다운 쿼터뷰 카메라 (전체 전장을 입체감 있게 한눈에 조망).
2. **3D 봄버 히어로 & 몬스터 AI**:
   - 플레이어: 봄버맨 수트, 스포티 헬멧, 등 뒤 No.082 공식 카드 영웅 배지 백팩 장착.
   - 적 몬스터: 슬라임/고블린 3D 몬스터 5마리, 미로를 배회하며 플레이어를 발견 시 접근.
3. **폭탄 설치 및 십자 화염 연쇄 폭발 시스템**:
   - **폭탄 설치 (BOMB)**: 도화선에서 연기가 피어오르는 3D 구형 폭탄 설치 (2.0초 후 폭발).
   - **십자 화염 (Cross Fire Stream)**: 상하좌우로 뻗어나가는 3D 불기둥 및 파티클.
   - **연쇄 폭발 (Chain Reaction)**: 화염이 다른 폭탄이나 폭발 드럼통에 닿으면 즉시 연쇄 폭발!
   - **아이템 파밍**: 상자 파괴 시 폭탄 개수(+1), 화력 범위(+1), 스피드 부스트 아이템 드롭.
4. **승리 조건**:
   - 미로 내의 모든 몬스터(5마리)를 소탕하면 클리어 및 탈출 포털 개방!

---

## 3. 100% 모바일 퓨어 터치 조작계
- **화면 좌측**: 360° 다이나믹 플로팅 가상 조이스틱 (Screen-relative 완벽 일치).
- **화면 우측 액션 버튼 군**:
  - **76px [BOMB]**: 폭탄 설치 대형 버튼 (설치 시 햅틱).
  - **64px [REMOTE]**: 리모컨 폭탄 원격 기폭 / 전력 대시.
- **햅틱 피드백**: 폭탄 설치 시 진동(`navigator.vibrate(25)`), 대폭발 시 강력 진동(`navigator.vibrate([40, 60, 80])`).

---

## 4. UI & 시스템 연동
- **전체화면 무결점**: `fixed inset-0 w-full h-[100dvh] overflow-hidden select-none touch-none`.
- **MinimalistMissionHUD**: 몬스터 소탕 수(x/5), 남은 폭탄 수, 중도 포기 확인 모달, 실적 비례 20~50 SNS 안전 정산.
- **LocalStorage 100% 영구 보존**: `standardizedRewardGateway.ts` 완벽 통합.
