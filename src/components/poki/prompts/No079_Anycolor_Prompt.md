# No.079 Anycolor - Three.js 3D 힐링 아트 피규어 컬러링 & 팔레트 스튜디오

## 1. 개요
- **게임명**: Anycolor (애니컬러 3D)
- **장르**: 장식 게임, 3D 컬러링 시뮬레이션, 힐링 아트 퍼즐
- **플랫폼**: Poki 웹게임 Top 110선 No.079
- **원작 URL**: `https://poki.com/kr/g/anycolor`
- **엔진**: Three.js (WebGL 3D) + React 19 + TypeScript + Tailwind CSS

---

## 2. 핵심 게임 메커니즘 & 3D 연출
1. **3D 아뜰리에 스튜디오 룸 (Art Studio Room)**:
   - 따뜻한 갤러리 조명, 원형 회전 디스플레이 턴테이블, 벽면 액자에 걸린 No.079 공식 카드 영웅 배지 명화.
   - 직관적인 3D 궤도 회전 카메라 (손가락 드래그로 모델을 상하좌우 360도 돌려보며 숨은 면까지 관찰).
2. **3D 히어로 메카/가디언 입체 피규어 (32개 분할 파츠)**:
   - 헬멧, 바이저, 윙, 숄더 가드, 체스트 코어, 건틀릿, 벨트, 부츠 등 32개 정밀 3D 블록 파츠.
   - 각 파츠는 1~6번 넘버가 부여되어 미채색 상태(회색 와이어프레임 톤)에서 번호 색상으로 채색 대기.
3. **인터랙티브 컬러링 & 특수 연출**:
   - **번호별 매칭 채색 (PAINT)**: 선택한 번호와 일치하는 파츠를 터치하면 산뜻한 바운스 팝업 및 스파클 파티클과 함께 아름다운 컬러로 변환.
   - **매직 필 (MAGIC FILL)**: 64px 매직필 버튼으로 현재 선택 번호의 모든 미채색 파츠를 한 번에 자동 완성.
   - **완성 세레모니**: 32개 파츠 100% 채색 시 조명이 화려하게 바뀌며 피규어가 공중으로 부유해 360도 회전하는 쇼케이스 연출.
4. **승리 & 정산**:
   - 100% 완성 시 승리 모달 및 SNS 보상 지급 (중도 포기 시에도 채색 진행률 비례 안전 정산).

---

## 3. 100% 모바일 퓨어 터치 조작계
- **화면 터치 드래그**: 3D 피규어 상하좌우 360° 자유 궤도 회전.
- **화면 하단 6색 팔레트 바**:
  - 1: 루비 레드 (`#ef4444`)
  - 2: 로열 블루 (`#3b82f6`)
  - 3: 골든 앰버 (`#f59e0b`)
  - 4: 에메랄드 그린 (`#10b981`)
  - 5: 네온 바이올렛 (`#8b5cf6`)
  - 6: 펄 화이트 (`#f8fafc`)
- **화면 우측 액션 버튼 군**:
  - **76px [PAINT]**: 현재 조준된 파츠 채색.
  - **64px [MAGIC FILL]**: 선택 색상 전체 일괄 채색.
- **햅틱 피드백**: 채색 시 경쾌한 진동(`navigator.vibrate(20)`), 100% 완성 시 승리 진동(`navigator.vibrate([40, 60, 40, 80])`).

## 4. UI & 시스템 연동
- **전체화면 무결점**: `fixed inset-0 w-full h-[100dvh] overflow-hidden select-none touch-none`.
- **MinimalistMissionHUD**: 채색 완료율(%), 남은 파츠 수, 중도 포기 확인 모달, 실적 비례 20~50 SNS 안전 정산.
- **LocalStorage 100% 영구 보존**: `standardizedRewardGateway.ts` 완벽 통합.
