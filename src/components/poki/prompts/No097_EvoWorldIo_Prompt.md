# No.097 EvoWorld io (Three.js 3D 비행 생태계 진화 IO 서바이벌)

## 1. 게임 개요
- **원작 타이틀**: EvoWorld io / FlyOrDie io (`https://poki.com/kr/g/flyordie-io`)
- **장르**: 3D 비행 시뮬레이션 / 생태계 진화 IO / 서바이벌 어드벤처
- **플랫폼**: 모바일 웹 (Three.js + React 19 + TypeScript + Tailwind CSS)
- **공식 연동 영웅**: No.097 공식 카드 영웅 배지 (`cards1.png` / `cards2.png` 스프라이트 연동)

---

## 2. 게임 메커니즘 및 3D 구현 사양

### (1) 3D 오픈 스카이 생태계 필드
- **28m x 24m x 20m 3D 생태 챔버 필드**:
  - 하단: 푸른 호수 수면(Water 호수, 반사 효과) 및 수변 꽃밭과 베리 나무.
  - 중단: 맑은 하늘, 뭉게구름, 부유 섬들.
  - 상단: 고공 성층권, 붉은 노을 아우라.
  - 중앙 부유섬 No.097 공식 카드 영웅 배지 엠블럼 기념탑.

### (2) 5단계 3D 생물 진화 시스템
1. **[🪰 1단계: 플라이 (Fly)]**: 반투명 진동 날개, 겹눈, 등 뒤 No.097 공식 영웅 배지 엠블럼.
2. **[🦋 2단계: 버터플라이 (Butterfly)]**: 화려한 에메랄드/핑크 날개 펄럭임.
3. **[🦟 3단계: 모기 (Mosquito)]**: 고속 침투, 침 주둥이, 빠른 기동성.
4. **[🦅 4단계: 매 (Falcon)]**: 날카로운 부리, 활공 날개.
5. **[🔥 5단계: 피닉스 (Phoenix)]**: 타오르는 불꽃 파티클 아우라, 궁극의 공중 지배자!

### (3) 먹이 및 수분(Water) 생존 메커니즘
- 3D 먹이 오브젝트 (25개 이슬 방울, 베리 열매, 꽃 꿀): 접촉 시 EXP 획득 및 섭취 사운드/파티클.
- 수분(Water 0~100%) 시스템: 하단 호수면에 착수하거나 이슬 섭취 시 100% 리필.
- 상위 포식자 드래곤/독수리 AI: 붉은 경고 링을 띄우며 순찰, 충돌 시 체력 감소.
- 1,000 EXP 달성 및 피닉스 진화 시 승리 세레모니 및 콘페티 폭발!

### (4) 모바일 퓨어 터치 조작계
- **360° 다이나믹 플로팅 조이스틱**: 화면 터치 지점에 링과 놉이 부드럽게 나타나며 3차원 공중 자유 비행 (Screen-relative 완벽 일치).
- **76px [🔥 FLY BOOST] 대형 터보 가속 비행 버튼**.
- **64px [💧 DIVE / DRINK] 급강하 호수 잠수 / 수분 섭취 버튼**.
- 햅틱 진동 피드백 (`navigator.vibrate`) 연동.

---

## 3. 보상 및 UI 규격
- **MinimalistMissionHUD**: 현재 진화 단계(1/5 ~ 5/5), EXP 진행률, 수분 게이지(Water %), 중도 포기 확인 모달, 실적 비례 20~50 SNS 포인트 안전 정산.
- **VictoryRewardModal**: 피닉스 승천 시 360도 스카이 쇼케이스 세레모니 및 보상 지급.
- **LocalStorage 100% 영구 보존**: `calculateAndDepositMissionReward` 표준 게이트웨이 연동.
