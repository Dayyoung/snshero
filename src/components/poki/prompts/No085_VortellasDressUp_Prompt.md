# No.085 Vortella's Dress Up - Three.js 3D 고딕 마녀 스타일링 & 룬 마법 의식

## 1. 개요
- **게임명**: Vortella's Dress Up (보르텔라의 드레스업 3D)
- **장르**: 옷입히기, 고딕 판타지 스타일링, 3D 마법 의식 시뮬레이션
- **플랫폼**: Poki 웹게임 Top 110선 No.085
- **원작 URL**: `https://poki.com/kr/g/vortellas-dress-up`
- **엔진**: Three.js (WebGL 3D) + React 19 + TypeScript + Tailwind CSS

---

## 2. 핵심 게임 메커니즘 & 3D 연출
1. **3D 고딕 제단 성소 (Gothic Ritual Altar)**:
   - 회전하는 신비로운 퍼플 룬 마법진 바닥, 촛불 조명, 중앙 No.085 공식 카드 영웅 배지 엠블럼.
   - 손가락 터치 드래그로 3D 고딕 마녀를 360도 자유 궤도 회전.
2. **3D 보르텔라 마녀 & 다크 판타지 파츠 4종**:
   - [모자]: 심연의 뾰족 고깔모자, 달빛 깃털 모자, 붉은 장미 베일, 혼 마녀 티아라.
   - [로브]: 성운의 밤하늘 로브, 벨벳 레드 드레스, 다크 코르셋 가운, 에메랄드 주술 가운.
   - [오브]: 공중 부유 회전 예지력의 퍼플 오브, 영혼의 에메랄드 구, 블러드 루비 구, 스타라이트 골드 구.
   - [스태프]: 초승달 룬 지팡이, 흑요석 스태프, 스컬 데스 스태프, 크리스털 완드.
   - 아이템 변경 시 실시간 3D 착용 및 룬 마법 스파클 파티클 방출.
3. **룬 마법 의식 시전 (CAST RITUAL)**:
   - 76px [CAST RITUAL!] 버튼 클릭 시 제단의 마법진이 고속 회전하며 마녀가 공중 부유, 번개와 스파크가 폭발하는 시전 세레모니 및 승리 보상 지급!

---

## 3. 100% 모바일 퓨어 터치 조작계
- **화면 터치 드래그**: 3D 모델 360° 자유 회전.
- **하단 카테고리 탭 & 아이템 바**: 4개 카테고리별 4종 고딕 아이템 원터치 선택.
- **화면 우측 액션 버튼 군**:
  - **76px [CAST RITUAL!]**: 마법 의식 시전 대형 버튼.
  - **64px [AURA BOOST]**: 신비로운 룬 아우라 폭발.
- **햅틱 피드백**: 아이템 착용 시 진동(`navigator.vibrate(20)`), 주술 시전 시 강력 진동(`navigator.vibrate([40, 60, 80, 100])`).

## 4. UI & 시스템 연동
- **전체화면 무결점**: `fixed inset-0 w-full h-[100dvh] overflow-hidden select-none touch-none`.
- **MinimalistMissionHUD**: 마력 점수(100/100), 현재 카테고리, 중도 포기 확인 모달, 실적 비례 20~50 SNS 안전 정산.
- **LocalStorage 100% 영구 보존**: `standardizedRewardGateway.ts` 완벽 통합.
