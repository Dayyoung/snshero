# No.094 Phone CASE DIY (Three.js 3D 휴대폰 케이스 커스텀 공방)

## 1. 게임 개요
- **원작 타이틀**: Phone CASE DIY (`https://poki.com/kr/g/phone-case-diy`)
- **장르**: 3D 크리에이티브 시뮬레이션 / 캐주얼 커스텀 아트 / DIY 데코레이션
- **플랫폼**: 모바일 웹 (Three.js + React 19 + TypeScript + Tailwind CSS)
- **공식 연동 영웅**: No.094 공식 카드 영웅 배지 (`cards1.png` / `cards2.png` 스프라이트 연동)

---

## 2. 게임 메커니즘 및 3D 구현 사양

### (1) 3D 스마트폰 및 공방 씬
- **스튜디오 작업대**: 웜 파스텔 핑크/크림 톤의 3D 원형 턴테이블 작업대, 스튜디오 조명(Directional Light, Ambient Light, 상단 스포트라이트).
- **3D 스마트폰 모델링**:
  - 스마트폰 본체 (메탈릭 실버 프레임, 전면 블랙 디스플레이).
  - 후면 트리플 카메라 범프 섬 (3개 렌즈 및 플래시).
  - 탈착형 3D 실리콘/하드 폰 케이스 메쉬.
  - No.094 공식 카드 영웅 배지가 각인된 럭셔리 홀로그램 참(Charm) & 배지 엠블럼.

### (2) 4단계 DIY 커스텀 프로세스
1. **[🧼 1단계: 세척 (Clean & Prep)]**:
   - 더러워진 구형 케이스에 클리닝 폼을 도포하고 스펀지로 문질러 얼룩 제거.
   - 화면을 드래그하거나 76px [🧼 AUTO CLEAN] 버튼으로 거품 세척 (클리닝 진행도 100%).
2. **[🎨 2단계: 아크릴 스프레이 (Acrylic Spray)]**:
   - 5종 파스텔 네온 컬러 스프레이 (로즈 핑크, 스카이 블루, 민트 그린, 네온 라벤더, 선샤인 골드).
   - 3D 스프레이 노즐 분사 이펙트 및 동적 캔버스 텍스처 페인팅.
   - 케이스 표면 80% 이상 도색 완료 시 건조 단계 전환 (또는 76px [🎨 AUTO COAT] 버튼).
3. **[💨 3단계: 핫에어 건조 (Blow Dry)]**:
   - 3D 헤어드라이어 열풍 파티클 분사.
   - 케이스 표면이 글로시(Glossy) 고광택 셰이더로 마감되며 건조 진행도 100% 달성 (또는 76px [💨 INSTANT DRY] 버튼).
4. **[✨ 4단계: 스티커 & 참 데코레이션 (Decorate)]**:
   - 귀여운 3D 스티커/참(하트, 별, 유니콘, 번개, No.094 영웅 배지 참).
   - 원하는 위치에 3D 레이캐스팅 다이렉트 탭으로 부착.
   - 글리터 스파클 파티클 분출 및 완성 쇼케이스 360° 회전!

### (3) 모바일 퓨어 터치 조작계
- **3D 레이캐스팅**: 화면을 터치/드래그하여 케이스 표면에 직접 도색 및 스티커 부착.
- **360° 뷰 궤도 회전**: 빈 공간 터치 드래그로 폰 케이스를 원하는 각도로 회전 감상.
- **대형 액션 버튼**:
  - 76px [✨ NEXT / ACTION] 메인 액션 버튼.
  - 64px [🎨 PALETTE / STICKER] 팔레트 선택 버튼.
  - 햅틱 진동 피드백(`navigator.vibrate`) 연동.

## 3. 보상 및 UI 규격
- **MinimalistMissionHUD**: 현재 DIY 단계(1/4 ~ 4/4), 진행도 게이지, 중도 포기 확인 모달, 실적 비례 20~50 SNS 포인트 안전 정산.
- **VictoryRewardModal**: 케이스 완성 시 360도 회전 쇼케이스 축하 세레모니 및 보상 지급.
- **LocalStorage 100% 영구 보존**: `calculateAndDepositMissionReward` 표준 게이트웨이 연동.
