# Poki No.087: School Cleaning (Three.js 3D 리마스터 기획 프롬프트)

## 1. 게임 개요
- **게임명**: School Cleaning 3D
- **장르**: 3D 힐링 교실 청소 & 공간 정리 시뮬레이션
- **카테고리**: 캐주얼 게임, 시뮬레이션 게임, 스킬 게임
- **원작 URL**: https://poki.com/kr/g/school-cleaning
- **연동 카드**: No.087 영웅 카드 (`drawCardSprite` 교실 전면 영웅 액자 및 교탁 엠블럼)

## 2. 핵심 게임 메커니즘
1. **따뜻한 3D 교실 환경**:
   - 원목 마루 바닥, 크림 톤 벽면, 햇살이 들어오는 3개의 대형 창문, 전면 대형 흑판(칠판), 교탁.
   - 전면 벽면에 No.087 공식 카드 영웅 배지 액자 데코.
   - 6세트의 원목 학생 책상과 의자, 교실 코너 분리수거 쓰레기통 및 청소도구함.
2. **4단계 인터랙티브 청소 퀘스트**:
   - **바닥 쓰레기 수거 (5개)**: 음료수 캔, 구겨진 종이뭉치, 바나나 껍질, 우유팩, 과자 봉지 터치 시 쓰레기통으로 포물선 비행 안착.
   - **비뚤어진 책상 정렬 (3개)**: 삐뚤빼뚤하게 어질러진 책상을 터치하면 반듯하게 열 맞춰 자동 정렬.
   - **칠판 분필 낙서 지우기**: 낙서로 덮인 칠판을 터치/드래그하여 3D 분필 지우개로 깨끗하게 닦아내기.
   - **바닥 먼지 얼룩 대걸레 폴리싱 (3곳)**: 발자국 및 바닥 얼룩을 대걸레로 닦아내면 황금 스파클과 함께 눈부신 광택 효과.
3. **100% 청소 완료 세레모니**:
   - 청소 진행률 0%에서 100%까지 실시간 게이지 상승.
   - 100% 달성 시 교실 전체에 60개 무지개 축하 콘페티 파티클 분출 및 360도 교실 쇼케이스 회전.
4. **모바일 퓨어 터치 조작계**:
   - 3D 레이캐스팅으로 교실 내 청소 대상 오브젝트를 스마트폰 화면에서 직접 터치.
   - 화면 터치 드래그로 360도 쿼터뷰 궤도 자유 회전.
   - 하단 76px [🧹 AUTO CLEAN] 원터치 청소 실행 버튼 + 64px [✨ POLISH] 광택 버튼 + 햅틱 연동.
   - `MinimalistMissionHUD` (청소 진행도 100%, 포기 확인 모달, 실적 비례 20~50 SNS 안전 정산).

## 3. 기술 스택
- React 19 + TypeScript + Three.js + Tailwind CSS 4
- `drawCardSprite(heroCtx, 87, 18, 18, 220, 220, { circleClip: true })`
- `calculateAndDepositMissionReward` 표준 리워드 게이트웨이
