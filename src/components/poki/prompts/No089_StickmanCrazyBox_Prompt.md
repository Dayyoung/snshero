# Poki No.089: Stickman Crazy Box (Three.js 3D 리마스터 기획 프롬프트)

## 1. 게임 개요
- **게임명**: Stickman Crazy Box 3D
- **장르**: 3D 스틱맨 낙하 상자 회피 & 파쿠르 클라이밍 서바이벌
- **카테고리**: 액션 게임, 스킬 게임, 파티 게임
- **원작 URL**: https://poki.com/kr/g/stickman-crazy-box
- **연동 카드**: No.089 영웅 카드 (`drawCardSprite` 스틱맨 등 백팩 배지 및 아레나 중앙 바닥 엠블럼)

## 2. 핵심 게임 메커니즘
1. **3D 서바이벌 배틀 아레나**:
   - 18m x 18m 사이버 네온 팔각형 플랫폼 & 안전 외벽 (중앙 안전 스폰 안착).
   - 아레나 중앙 바닥에 No.089 공식 카드 영웅 배지 엠블럼 각인.
2. **3D 스틱맨 히어로**:
   - 다관절 스틱맨 모델링(머리, 몸통, 팔, 다리 달리기/점프 애니메이션).
   - 등 뒤 No.089 공식 카드 영웅 배지 백팩 장착.
   - 3하트 체력 시스템 (상자에 직격 깔림 시 1하트 감소 및 무적 시간).
3. **다이나믹 낙하 상자 (Falling Crazy Boxes)**:
   - 하늘에서 지면 그림자 경고 링(Warning Shadow)과 함께 낙하.
   - 우드 박스: 지면에 안전 착지하여 발판으로 변신 (올라타서 파쿠르 가능).
   - TNT 박스: 착지 2초 후 붉은 점멸과 함께 폭발(주변 파편 및 넉백 이펙트).
   - 골드 박스: 파괴 시 황금 별과 스파클 파티클 분출.
4. **황금 별(Gold Stars) 수집 퀘스트**:
   - 맵 곳곳 및 높은 상자 위에 생성되는 황금 별 8개 수집 시 승리!
   - 상자를 밟고 올라타는 박스 클라이밍(Box Climbing) 기술 필요.
5. **모바일 퓨어 터치 조작계 (100% 모바일 제스처)**:
   - 가상 D-패드 배제.
   - 좌측 360° 다이나믹 플로팅 조이스틱 (Screen-relative 100% 일치).
   - 우측 76px [⬆️ JUMP] 대형 점프 버튼.
   - 우측 64px [💨 DASH] 순간 무적 회피 대시 버튼 + 햅틱 연동.
   - `MinimalistMissionHUD` (별 8개 진행도, 하트 3개, 생존 시간, 실적 비례 20~50 SNS 안전 정산).

## 3. 기술 스택
- React 19 + TypeScript + Three.js + Tailwind CSS 4
- `drawCardSprite(heroCtx, 89, 18, 18, 220, 220, { circleClip: true })`
- `calculateAndDepositMissionReward` 표준 리워드 게이트웨이
