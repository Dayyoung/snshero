# Poki No.088: Hill Climb Racing Lite (Three.js 3D 리마스터 기획 프롬프트)

## 1. 게임 개요
- **게임명**: Hill Climb Racing Lite 3D
- **장르**: 3D 피직스 힐 클라이밍 & 오프로드 밸런스 드라이빙
- **카테고리**: 레이싱 게임, 스킬 게임, 피직스 게임
- **원작 URL**: https://poki.com/kr/g/hill-climb-racing-lite
- **연동 카드**: No.088 영웅 카드 (`drawCardSprite` 지프 도어 배지 및 시작 지점 평지 엠블럼)

## 2. 핵심 게임 메커니즘
1. **3D 롤링 힐스 지형 (Continuous Rolling Hills Terrain)**:
   - 400m 길이의 복합파 지형(가파른 언덕, 깊은 계곡, 점프 둔덕, 평탄한 능선).
   - 시작 지점 20m 안전 광폭 수평 평지 (스폰 즉시 전복 원천 방지).
   - 시작 지점 바닥에 No.088 공식 카드 영웅 배지 대형 엠블럼 각인.
2. **3D 클래식 힐 클라이머 레드 지프**:
   - 레드 섀시 바디, 블랙 롤케이지 프레임, 노출형 드라이버 피규어, 도어 No.088 영웅 배지 데칼.
   - 4개 오프로드 빅 타이어 및 독립 서스펜션 접지 시뮬레이션.
   - 배기 파이프 흙먼지 파티클 분출.
3. **엄격한 물리 엔진 & 전복(Neck Flip) 판정**:
   - GAS(가속) 시 후륜 구동 추진력 + 차체 뒤로 젖혀짐(공중 백플립).
   - BRAKE(제동/후진) 시 전륜 제동 + 차체 앞으로 쏠림(공중 프론트플립).
   - 차체가 135° 이상 뒤집혀 드라이버 머리가 지면에 충돌 시 Neck Flip 전복 판정 및 충돌 이펙트.
4. **연료(Fuel) & 코인 수집 시스템**:
   - 주행 시 실시간 연료 소모 (0% 도달 시 엔진 정지).
   - 코스에 배치된 붉은 제리캔(Gas Can) 획득 시 "FUEL 100%" 즉시 완충.
   - 3D 회전 골드 코인 수집(+50점).
5. **승리 및 보상**:
   - 350m 결승 체크 아치 통과 시 트로피 획득 및 승리 세레모니.
   - `MinimalistMissionHUD` (주행 거리, 연료 %, 코인, 포기 확인 모달, 실적 비례 20~50 SNS 안전 정산).

## 3. 모바일 터치 조작계 (100% 모바일 퓨어 제스처)
- 가상 D-패드 배제.
- 좌측 64px [🛑 BRAKE] (제동/공중 앞 틸트) 버튼.
- 우측 76px [⛽ GAS] (가속/공중 뒤 틸트) 대형 버튼.
- 원터치 홀드 & 릴리즈 감도 최적화, 햅틱(`navigator.vibrate`) 연동.

## 4. 기술 스택
- React 19 + TypeScript + Three.js + Tailwind CSS 4
- `drawCardSprite(heroCtx, 88, 18, 18, 220, 220, { circleClip: true })`
- `calculateAndDepositMissionReward` 표준 리워드 게이트웨이
