# No.100 Undead Slayer (Three.js 3D 다크 판타지 핵앤슬래시 언데드 토벌전)

## 1. 게임 개요
- **원작 타이틀**: Undead Slayer (`https://poki.com/kr/g/undead-slayer`)
- **장르**: 3D 액션 RPG / 핵앤슬래시 / 언데드 웨이브 서바이벌
- **플랫폼**: 모바일 웹 (Three.js + React 19 + TypeScript + Tailwind CSS)
- **공식 연동 영웅**: No.100 공식 카드 영웅 배지 (`cards1.png` / `cards2.png` 스프라이트 연동)

---

## 2. 게임 메커니즘 및 3D 구현 사양

### (1) 3D 고대 사원 전장 아레나
- **20m x 20m 다크 템플 스톤 그라운드**:
  - 돌벽 및 횃불 기둥 4기 (불꽃 스파크 조명 효과).
  - 중앙 신전 제단 석판 상단 No.100 공식 카드 영웅 배지 엠블럼.
  - 쿼터뷰 3D 시점 카메라 (플레이어를 중심으로 부드러운 다이나믹 트래킹).

### (2) 3D 슬레이어 무사 모델링
- 다크 아머 섀시 및 붉은 전포 스카프, 등 뒤 No.100 공식 카드 영웅 배지 문장.
- 거대 언월도 대검 (공격 시 청록빛 검기 슬래시 아크 궤적).
- 발 아래 황금 전투 인디케이터 링.

### (3) 3D 언데드 몬스터 군단 & 전투 물리
- 스켈레톤 전사 및 언데드 괴수 몬스터 (붉은 눈빛, 근접 추격 AI).
- 핵앤슬래시 타격감: 검에 닿은 몬스터는 피격 넉백과 함께 슬래시 이펙트 파티클 방출.
- [🌪️ WHIRLWIND] 360° 광역 회전 참격으로 주변 모든 언데드 괴멸.
- 목표 토벌 수: 언데드 25마리 퇴치(TARGET_KILLS = 25) 시 대지 정화 승리!

### (4) 모바일 퓨어 터치 조작계
- **360° 다이나믹 플로팅 조이스틱**: 화면 터치 지점 생성 이동 (Screen-relative 완벽 일치).
- **76px [⚔️ SLASH] 대형 연속 참격 공격 버튼**.
- **64px [🌪️ WHIRLWIND] 360도 광역 회오리 베기 필살기 버튼**.
- 햅틱 진동 피드백 (`navigator.vibrate`) 연동.

---

## 3. 보상 및 UI 규격
- **MinimalistMissionHUD**: 토벌 진행도(0/25), HP(100%), 콤보 카운트, 중도 포기 확인 모달, 실적 비례 20~50 SNS 포인트 안전 정산.
- **VictoryRewardModal**: 전장 정화 시 360도 승리 쇼케이스 세레모니 및 보상 지급.
- **LocalStorage 100% 영구 보존**: `calculateAndDepositMissionReward` 표준 게이트웨이 연동.
