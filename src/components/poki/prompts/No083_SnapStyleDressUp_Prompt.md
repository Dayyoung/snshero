# No.083 SnapStyle Dress Up - Three.js 3D 런웨이 패션 스타일링 & 포토 스냅샷

## 1. 개요
- **게임명**: SnapStyle Dress Up (스냅스타일 드레스업 3D)
- **장르**: 옷입히기, 패션 스타일링, 3D 포토슛 시뮬레이션
- **플랫폼**: Poki 웹게임 Top 110선 No.083
- **원작 URL**: `https://poki.com/kr/g/snapstyle-dress-up`
- **엔진**: Three.js (WebGL 3D) + React 19 + TypeScript + Tailwind CSS

---

## 2. 핵심 게임 메커니즘 & 3D 연출
1. **3D 패션 런웨이 스튜디오 (Runway Photo Studio)**:
   - 미러 리플렉션 턴테이블 무대, 핑크 & 퍼플 네온 스튜디오 조명, 배경 스크린 No.083 공식 영웅 배지 엠블럼.
   - 손가락 터치 드래그로 3D 모델을 상하좌우 360도 회전하며 완벽한 핏 감상.
2. **3D 패션 아바타 모델 & 인터랙티브 드레스업**:
   - 4개 스타일 카테고리:
     - [헤어]: 골든 포니테일, 핑크 웨이브 롱, 사이버 블루 밥, 다크 트윈테일.
     - [상의]: 크롭 레더 재킷, 오버핏 후디, 홀로그램 블레이저, 오프숄더 탑.
     - [하의]: 와이드 카고 팬츠, 네온 플리츠 스커트, 디스트로이드 데님, 슬림 슬랙스.
     - [액세서리]: 캣아이 틴트 선글라스, 체인 숄더백, 럭셔리 토트백, 골드 초커.
   - 아이템 변경 시 3D 실시간 파츠 교체 및 스파클 파티클 방출.
3. **포즈 변경 & 셔터 스냅샷 연출**:
   - **포즈 변경 (POSE)**: 런웨이 워킹, 핸즈온힙(Hands on hip), 모델 윙크 포즈 등 3가지 3D 포즈 전환.
   - **스냅샷 촬영 (SNAP PHOTO)**: 76px 셔터 버튼 클릭 시 눈부신 플래시 이펙트와 함께 폴라로이드 포토 프레임 완성 및 승리 세레모니!

---

## 3. 100% 모바일 퓨어 터치 조작계
- **화면 터치 드래그**: 3D 모델 360° 자유 회전.
- **하단 카테고리 탭 & 아이템 바**: 4개 카테고리별 4종 프리미엄 아이템 원터치 선택.
- **화면 우측 액션 버튼 군**:
  - **76px [SNAP PHOTO!]**: 셔터 플래시 스냅샷 촬영 대형 버튼.
  - **64px [POSE]**: 3D 런웨이 포즈 변경.
  - **64px [NEXT]**: 다음 카테고리 이동.
- **햅틱 피드백**: 아이템 착용 시 진동(`navigator.vibrate(20)`), 사진 촬영 시 셔터 진동(`navigator.vibrate([30, 40, 60])`).

## 4. UI & 시스템 연동
- **전체화면 무결점**: `fixed inset-0 w-full h-[100dvh] overflow-hidden select-none touch-none`.
- **MinimalistMissionHUD**: 패션 완성도 점수, 현재 카테고리, 중도 포기 확인 모달, 실적 비례 20~50 SNS 안전 정산.
- **LocalStorage 100% 영구 보존**: `standardizedRewardGateway.ts` 완벽 통합.
