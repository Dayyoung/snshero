# No.101 Watermelon Drop (Three.js 3D 수박게임 과일 머지 & 드롭 물리 퍼즐)

## 1. 게임 개요
- **원작 타이틀**: Watermelon Drop (`https://poki.com/kr/g/watermelon-drop`)
- **장르**: 3D 물리 머지 퍼즐 / 과일 합성 시뮬레이션 / 캐주얼 브레인
- **플랫폼**: 모바일 웹 (Three.js + React 19 + TypeScript + Tailwind CSS)
- **공식 연동 영웅**: No.101 공식 카드 영웅 배지 (`cards1.png` / `cards2.png` 스프라이트 연동)

---

## 2. 게임 메커니즘 및 3D 구현 사양

### (1) 3D 투명 아크릴 컨테이너 챔버
- **가로 8.0m x 높이 10.0m x 깊이 2.4m 투명 글래스 박스**:
  - 반투명 유리 벽면 및 네온 엣지 와이어프레임.
  - 챔버 상단 No.101 공식 카드 영웅 배지 홀로그램 네온 간판.
  - 상단 클라우드 드롭퍼 (좌우 슬라이드 에임 가이드).

### (2) 6단계 3D 과일 티어 모델링
1. **[🍒 체리 (Cherry)]**: 반경 0.4m, 루비 레드, +10점.
2. **[🍓 딸기 (Strawberry)]**: 반경 0.6m, 핫핑크 & 꼭지 잎사귀, +25점.
3. **[🍇 포도 (Grape)]**: 반경 0.85m, 로열 퍼플, +50점.
4. **[🍊 오렌지 (Orange)]**: 반경 1.15m, 탠저린 오렌지, +90점.
5. **[🍎 사과 (Apple)]**: 반경 1.5m, 크림슨 레드, +150점.
6. **[🍉 수박 (Watermelon)]**: 반경 2.0m, 에메랄드 줄무늬 거대 수박, +300점!

### (3) 3D 구체 충돌 물리 & 진화 머지
- 중력 가속도, 구름 마찰, 바닥 및 벽면 탄성 반발 물리.
- 동일한 티어의 두 과일이 충돌 시 즉시 하나로 합체(Merge)되며 상위 티어로 진화!
- 합체 시 화려한 과즙 팝 파티클 분출 및 콤보 스코어 획득.
- 800점 달성 또는 거대 수박 탄생 시 축하 콘페티 피날레!

### (4) 모바일 퓨어 터치 조작계
- **화면 터치 드래그**: 상단 드롭퍼 좌우 이동 (Screen-relative 완벽 일치).
- **76px [🍉 DROP FRUIT!] 대형 투하 버튼**: 즉시 낙하 투하.
- **64px [🔀 SHAKE BOX] 박스 미세 진동 흔들기 버튼**: 갇힌 과일 자리잡기.
- 햅틱 진동 피드백 (`navigator.vibrate`) 연동.

---

## 3. 보상 및 UI 규격
- **MinimalistMissionHUD**: 현재 점수, 목표 800점 진행률, 다음 과일 프리뷰, 중도 포기 확인 모달, 실적 비례 20~50 SNS 포인트 안전 정산.
- **VictoryRewardModal**: 목표 달성 시 360도 수박 쇼케이스 세레모니 및 보상 지급.
- **LocalStorage 100% 영구 보존**: `calculateAndDepositMissionReward` 표준 게이트웨이 연동.
