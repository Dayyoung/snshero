# No.058 Tear Blocks Down 3D 리마스터 기획 및 설계 프롬프트

## 1. 게임 개요
- **게임명**: Tear Blocks Down 3D (티어 블록스 다운 3D)
- **원작 식별**: Poki 인기 순위 58위 (`https://poki.com/kr/g/tear-blocks-down`)
- **장르**: 3D 물리 기반 블록 파괴 슈팅 / 구조물 붕괴 퍼즐
- **기술 스택**: React 19 + Three.js + TypeScript + Tailwind CSS
- **연동 카드**: No.058 공식 영웅 배지 (`drawCardSprite(ctx, 58, ...)`)

## 2. 3D 그래픽 및 전장 연출
1. **3D 파괴 시험장 환경**:
   - 40x50m 체커보드 그리드 전장, 배경 사이버네틱 네온 스카이 및 안전 배리어.
   - 플레이어 포대 진지: 남쪽 16m 안전 사격 발판 (스폰 즉시 급사 원천 차단).
   - 타워 구역: 중앙 북쪽 12m 지점에 축조된 3D 다층 블록 구조물.

2. **3D 블록 & 타겟 모델링**:
   - **우드 블록 (갈색 목재)**: 기본 물리 블록, 충격 시 튕겨나가고 붕괴.
   - **스톤 블록 (회색 석재)**: 단단하고 무거운 물리 블록.
   - **TNT 폭약 블록 (붉은색 & 위험 마크)**: 충격 시 1.5초 후 대폭발하여 주변 블록과 좀비를 사방으로 날려버림.
   - **3D 타겟 좀비 (초록색 복셀 좀비)**: 블록 타워 꼭대기 및 틈새에 서 있는 타겟, 타워 붕괴로 바닥에 떨어지거나 포탄에 직격당하면 래그돌 물리로 날아가며 처치.
   - **3D 대포 (플레이어 캐논)**:
     - 중후한 주철 캐논 바렐, 회전 마운트, No.058 공식 영웅 카드 배지 부착.
     - 발사 시 화염 플래시 및 백색 연기 파티클, 포신 후퇴 반동(Recoil) 애니메이션.

3. **카메라 워크**:
   - TPS 쿼터뷰 사격 시점: 캐논 후방 측면에서 타워 전체와 탄도 궤적이 시원하게 한눈에 들어오는 와이드 카메라.
   - 포탄 비행 시 다이내믹 포커싱 및 블록 타격 시 임팩트 셰이크.

## 3. 핵심 게임플레이 및 3단계 스테이지
1. **3단계 파괴 스테이지**:
   - **Stage 1 (우드 타워)**: 3층 목재 타워 + 좀비 2마리. 포탄 4발 지급.
   - **Stage 2 (TNT 연쇄 폭탄)**: 4층 복합 타워 중앙에 TNT 2개 배치 + 좀비 3마리. 연쇄 폭발로 일망타진. 포탄 4발 지급.
   - **Stage 3 (메가 캐슬 요새)**: 5층 광폭 캐슬 요새 + 기둥 TNT + 좀비 4마리. 포탄 5발 지급. 클리어 시 최종 승리!

2. **모바일 퓨어 터치 인터랙션 (Pure Touch Control)**:
   - **터치 슬라이드 조준**: 화면 어디서나 터치 드래그로 대포의 좌우 회전각과 상하 앙각을 부드럽게 조절.
   - **실시간 3D 탄도 궤적 아크**: 3D 점선(Dashed Line)으로 포탄의 낙하 지점과 포물선 궤도를 실시간 시각화.
   - **우측 대형 [FIRE 발사] 버튼 (76px)**: 터치 즉시 시원한 대포 발사 + 포신 반동 + 햅틱 진동.
   - 타격 및 폭발 시 강력한 햅틱(`navigator.vibrate`) 피드백.

3. **UI 및 표준 보상 정산**:
   - 상단 MinimalistMissionHUD: 현재 스테이지, 남은 좀비 수, 남은 포탄 수, 점수.
   - VictoryRewardModal: 3개 스테이지 전원 붕괴 완료 시 35~50 SNS 포인트 및 영웅 카드 No.058 정산.
