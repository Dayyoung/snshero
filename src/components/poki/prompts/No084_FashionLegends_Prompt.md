# No.084 Fashion Legends - Three.js 3D 캣워크 런웨이 러너 & 오뜨 꾸뛰르 심사 배틀

## 1. 개요
- **게임명**: Fashion Legends (패션 레전드 3D)
- **장르**: 런웨이 러너, 패션 스타일링 배틀, 3D 캣워크 시뮬레이션
- **플랫폼**: Poki 웹게임 Top 110선 No.084
- **원작 URL**: `https://poki.com/kr/g/fashion-legends`
- **엔진**: Three.js (WebGL 3D) + React 19 + TypeScript + Tailwind CSS

---

## 2. 핵심 게임 메커니즘 & 3D 연출
1. **3D 메가 런웨이 캣워크 트랙 (80m Mega Catwalk)**:
   - 80m 글래스 네온 런웨이 (시작 지점 15m 안전 광폭 스타트 존, 양옆 스포트라이트 조명 및 관중 플래시, 트랙 중앙 No.084 공식 영웅 배지 엠블럼).
   - 3.5D 스무스 3인칭 숄더 팔로우 카메라 (모델의 당당한 캣워크 워킹을 파노라마로 추적).
2. **3D 패션 슈퍼모델 & 실시간 의상 변환 (Morphing)**:
   - 3D 모델 캐릭터: 당당한 하이패션 워킹 보행 애니메이션, 목걸이 No.084 영웅 배지 펜던트.
   - 3쌍의 스타일 선택 게이트:
     - 1차 게이트 (20m): 럭셔리 골드 이브닝 드레스 vs 캐주얼 티셔츠
     - 2차 게이트 (40m): 크리스털 하이힐 vs 낡은 스니커즈
     - 3차 게이트 (60m): 다이아몬드 티아라 왕관 vs 털모자
   - 올바른 게이트 통과 시 모델의 3D 의상이 실시간으로 고광택 럭셔리 드레스로 즉시 변신 및 스파클 파티클 폭발!
3. **종점 심사위원 포디움 & 만점 세레모니 (Judging Podium)**:
   - 75m 종점 포디움 도착 시 360도 모델 턴 포즈!
   - 3명의 심사위원이 채점(10, 10, 10점 만점)을 발표하며 꽃가루 컨페티 폭발 및 우승 트로피 수여.

---

## 3. 100% 모바일 퓨어 터치 조작계
- **화면 하단 터치 슬라이더**: 캣워크 런웨이 좌우 부드러운 라인 조향 (Screen-relative 완벽 일치).
- **화면 우측 액션 버튼 군**:
  - **76px [STRUT & POSE]**: 워킹 가속 및 모델 턴 포즈 대형 버튼.
  - **64px [STYLE BOOST]**: 순간 패션 스파클 아우라 부스트.
- **햅틱 피드백**: 게이트 통과 시 진동(`navigator.vibrate(30)`), 만점 세레모니 시 축하 진동(`navigator.vibrate([40, 50, 60, 80])`).

## 4. UI & 시스템 연동
- **전체화면 무결점**: `fixed inset-0 w-full h-[100dvh] overflow-hidden select-none touch-none`.
- **MinimalistMissionHUD**: 패션 스코어(0~100점), 런웨이 완주율(%), 중도 포기 확인 모달, 실적 비례 20~50 SNS 안전 정산.
- **LocalStorage 100% 영구 보존**: `standardizedRewardGateway.ts` 완벽 통합.
