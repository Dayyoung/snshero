# Poki No.091: Hexellent (Three.js 3D 리마스터 기획 프롬프트)

## 1. 게임 개요
- **게임명**: Hexellent 3D
- **장르**: 3D 육각 허니컴 블록 매칭 & 클러스터 블래스트 퍼즐
- **카테고리**: 두뇌 퍼즐, 캐주얼 게임, 스킬 게임
- **원작 URL**: https://poki.com/kr/g/hexellent
- **연동 카드**: No.091 영웅 카드 (`drawCardSprite` 허니컴 보드 상단 엠블럼 및 배경 중앙 각인)

## 2. 핵심 게임 메커니즘
1. **3D 사이버 허니컴 보드**:
   - 37개 육각 슬롯으로 구성된 반경 3 허니컴 챔버.
   - 보드 상단 및 중앙 바닥에 No.091 공식 카드 영웅 배지 대형 네온 엠블럼 각인.
2. **5종 보석 육각 프리즘 타일**:
   - 루비 레드, 사파이어 블루, 에메랄드 그린, 앰버 골드, 아메시스트 바이올렛.
   - 각 타일은 정교한 6각 프리즘 메쉬와 베벨 림 엣지.
3. **클러스터 매치 & 연쇄 폭발 (Chain Blast)**:
   - 인접한 동일 색상 육각 타일 그룹(최소 2개 이상) 터치 시 화려한 폭발 파티클과 함께 파괴.
   - 블록 파괴 후 상공에서 새로운 육각 프리즘이 중력 낙하하며 리필.
   - 연쇄 콤보(COMBO x2, x3, x4...) 달성 시 보너스 점수 폭증.
   - 목표 점수: 1,500점 달성 시 승리 세레모니 및 콘페티 분출.
4. **모바일 퓨어 터치 조작계 (100% 모바일 제스처)**:
   - 3D 레이캐스팅 다이렉트 터치로 육각 타일 클러스터 폭파.
   - 화면 터치 드래그로 보드 3D 쿼터뷰 미세 틸트 회전 (Screen-relative 완벽 일치).
   - 하단 76px [💥 MEGA BLAST] 원터치 최대 클러스터 자동 폭파 힌트/실행 버튼 + 64px [🎲 SHUFFLE] 보드 셔플 버튼 + 햅틱 연동.
   - `MinimalistMissionHUD` (목표 점수 1500점 진행도, 콤보 수, 포기 확인 모달, 실적 비례 20~50 SNS 안전 정산).

## 3. 기술 스택
- React 19 + TypeScript + Three.js + Tailwind CSS 4
- `drawCardSprite(heroCtx, 91, 18, 18, 220, 220, { circleClip: true })`
- `calculateAndDepositMissionReward` 표준 리워드 게이트웨이
